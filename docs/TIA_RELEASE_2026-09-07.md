- ۲۴۷ تست، Type Check، Lint، Build وب، Android Lint، تست‌های واحد Android و ساخت APK موفق‌اند. بسته واقعی APK از نظر وجود و SHA مدل فشرده کنترل شد.

- مرورگر واقعی دسکتاپ/موبایل، نمونه صوتی فارسی، لغو و مسیر خطای میکروفون بررسی شدند. عرض‌های ۱۲۸۰، ۳۹۰ و ۳۲۰ بدون سرریز افقی بودند. ۴۲ کنترل HTTP روی هر یک از لوکال و Staging موفق‌اند؛ سلامت Staging منبع بالا را گزارش می‌دهد و فایل مدل جدید HTTP 200 دارد.

۱. نسخه ۳۴ فقط ضبط داشت؛ تبدیل فعال به کلید/هزینه وابسته بود. مسیر مستقل تشخیص محلی اضافه شد.
