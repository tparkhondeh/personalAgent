## معماری

- `src/lib/appearance.ts`: اسکریپت مشترک پیش از نمایش؛ فقط light/dark معتبر، کلید جداگانه، تحمل نبود دسترسی ذخیره‌سازی.
- `src/app/globals.css`: مرجع رنگ؛ تولید خودکار `mobile-shell/theme.css` و رنگ‌های بومی Android از همین منبع. انتخابگرهای صریح و تخت CSS با WebView قدیمی سازگارند؛ وابستگی خودکار به prefers-color-scheme حذف شد.
- Android پیش از اولین `loadUrl` تم را در سند تزریق می‌کند. پیام تغییر فقط از main frame دو origin معتبر و فقط با مقدار light/dark پذیرفته می‌شود؛ SharedPreferences انتخاب را میان صفحه متصل و محلی یکسان نگه می‌دارد. صفحه بازیابی نیز مقدار بومی را هم‌زمان دریافت می‌کند.
- Android 12+ از per-app night mode برای هماهنگی Splash استفاده می‌کند؛ اجزای Loading و نوارهای سیستم هم تنظیم می‌شوند. WebView فاقد Document Start از قابلیت‌های موجود/بازیابی محلی استفاده می‌کند؛ نتیجه روی نسخه‌های هدف باید آزموده شود، نه فرض.
- چهار مصراع دو ردیف و دو ستون RTL هستند؛ متن بلند در همان ستون می‌شکند، کوچک‌سازی افراطی یا برش نداریم. فاصله‌ها، کارت‌های امروز، تنظیمات و همراه کوتاه‌تر شدند؛ فرم تأیید و قراردادهای امنیتی تغییر نکردند.
- cache پوسته PWA نسخه جدید دارد؛ داده‌های کاربر پاک نمی‌شوند.
