# اپلیکیشن Android همراه

اپ اندروید با Capacitor 8 ساخته شده و کد اصلی وب را دوباره‌نویسی نمی‌کند. پوشه `android/` پروژه بومی و `mobile-shell/` پوسته امن آفلاین است.

## وضعیت فعلی

- شناسه برنامه: `ir.wealthos.personalagent`
- نام برنامه: «همراه»
- حداقل Android: API 24
- Target: API 36
- RTL، حالت روشن/تاریک، آیکون، Splash و فونت محلی آماده است.
- اعلان محلی و Alarm دقیق با مجوز روشن کاربر پیاده‌سازی شده است.
- پیامک و تماس فقط Mock هستند و هیچ داده یا هزینه‌ای ایجاد نمی‌کنند.

## ساخت نسخه آزمایشی

نسخه Emulator به برنامه لوکال روی پورت ۳۰۰۱ وصل می‌شود:

```powershell
pnpm android:assets
pnpm android:build:debug
```

خروجی پس از نصب Android SDK در مسیر زیر ساخته می‌شود:

`android/app/build/outputs/apk/debug/app-debug.apk`

برای اجرای این دستور، JDK و Android SDK لازم‌اند. فایل `local.properties`، Keystore و APK وارد Git نمی‌شوند.

## نسخه انتشار

`server.url` فقط در Build آزمایشی Emulator استفاده می‌شود. نسخه انتشار باید پس از تأیید Production با آدرس HTTPS نهایی و تنظیم امن احراز هویت ساخته شود. هیچ آدرس HTTP عمومی در Release پذیرفته نمی‌شود.

## محدودیت آگاهانه هشدار تمام‌صفحه

هشدار تمام‌صفحه برای برنامه‌های عادی بهره‌وری در نسخه‌های جدید Android محدود است. همراه از کانال اعلان با بیشترین اولویت، صدا، لرزش و Alarm دقیقِ دارای رضایت استفاده می‌کند و محدودیت سیستم‌عامل را دور نمی‌زند.
